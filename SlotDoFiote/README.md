# SlotDoFiote

Este projeto foi criado como um esqueleto para o jogo de slot machine 2D solicitado.

Estrutura de pastas:
- `Assets/Scripts/` para scripts C#.
- `Assets/Sprites/` para sprites.
- `Assets/Prefabs/` para prefabs.
- `Assets/Scenes/` para cenas do Unity.

Para abrir o projeto, utilize o Unity 2021.3 ou superior.
